# Лабораторная работа №5

## Тема

Изучение циклического избыточного кода (CRC).

## Исходные данные

- Номер в журнале: 19
- Длина исходного сообщения для пункта 1: \(N = 39\) бит
- Длина сообщения для пункта 4: \(N = 250\) бит
- Порождающий полином: \(G(x) = x^7 + x^6 + x + 1\)
- Двоичное представление полинома: `11000011`
- Длина CRC: 7 бит
- Длина передаваемого пакета: \(N + 7\) бит

## Структура проекта

- `src/CRC.c` - исходный код программы на C
- `report/0_main.pdf` - отчёт по лабораторной работе

## Запуск C-программы

```bash
cd src
gcc CRC.c -o CRC
./CRC
```

## Выполненные задания

1. Генерация сообщения из 39 бит и вычисление CRC.
2. Формирование передаваемого пакета из сообщения и контрольной последовательности.
3. Проверка правильности принятого пакета.
4. Исследование обнаружения ошибок для сообщения длиной 250 бит.
5. Проверка обнаружения одиночной ошибки во всех 257 позициях пакета.

## Результат

Для пакета длиной 257 бит проверяются все возможные положения одиночной ошибки. Ожидаемый результат - обнаружение всех 257 одиночных ошибок.
